# Лаунчер кооператива Warband через Radmin VPN

Окно «в одну кнопку» для мода [**Warband Coop Campaign**](https://github.com/zABUz-rgb/Warband-Coop-Campaign).
Мод даёт общую карту Кальрадии на 2–4 игроков: мир живёт у хоста, у каждого свой отряд на той же карте,
бои вы проводите вместе на мультиплеерном сервере Warband. Лицензия мода — MIT, есть русская версия,
работа через Radmin VPN — его основной сценарий.

Лаунчер код мода не меняет. Он делает за вас всё, что раньше делалось руками: ищет игру, ставит
и обновляет мод, проверяет Radmin и связь с хостом, правит настройки Warband, запускает мост мода
и открывает игру.

## Что нужно

- Лицензионная **Mount & Blade: Warband 1.174** (Steam или GOG) у каждого игрока, с ключом для мультиплеера.
- **Radmin VPN**: хост создаёт сеть, друзья в неё входят. Если Radmin нет, его предложит поставить
  установщик мода.
- Python 3: его тоже ставит установщик мода.

## Установка лаунчера

1. Скачайте папку `launcher/` из этого репозитория: `CoopLauncher.bat`, `CoopLauncher.ps1`,
   `CoopLauncher_Check.bat`. Положите её куда угодно, например на рабочий стол.
2. Дважды щёлкните **`CoopLauncher.bat`**.
3. Первый раз нажмите **«Установить / обновить мод»**. Лаунчер скачает последний релиз мода с GitHub
   (около 130 МБ), распакует его в `%LOCALAPPDATA%\WarbandCoopLauncher\package` и запустит установщик
   мода. Установщик найдёт игру и предложит Python и Radmin VPN, если их нет.
   Если архив мода уже скачан и распакован, вместо этого выберите **Папки… → Указать папку пакета мода**.
4. В лаунчере Warband один раз задайте язык. Оконный режим лаунчер включит сам.

## Игра

### Хост (мир живёт на его ПК)
1. **«Я хост»**, ваш ник, придуманный пароль → **ИГРАТЬ**.
2. **«Скопировать приглашение друзьям»**: в буфер попадут ваш Radmin IP, пароль и версия мода. Отправьте это в чат.
3. В открывшемся Warband загрузите кампанию → Лагерь → «CoopWorld: кооператив…» →
   «сделать эту игру СЕРВЕРОМ МИРА и играть в ней (хост)».
4. Для каждого друга: там же «удержать мир для подключения игрока» → Esc → Сохранить.

### Друг
1. **«Подключаюсь к другу»**, ник, IP хоста (26.x.x.x из Radmin), пароль → **ИГРАТЬ**.
2. Лаунчер соединится с хостом, скачает его сохранение и откроет Warband. В строке статуса будет
   слот, например `sg00`. Загрузите его и подождите около 5 секунд: игра станет клиентом мира хоста.

### Совместные бои
Кнопка **«Второе окно для совместного боя»**:
- хост: Мультиплеер → Создать игру, режим «Битва», боты 0;
- друг: Сетевая игра → Присоединиться → Локальная сеть → Обновить, заходите под тем же ником.
  Если в списке два одинаковых сервера, один из них идёт напрямую через Radmin и выдаёт «неправильный номер
  авторизации». Заходите в другой и добавьте его в избранное.

**Не закрывайте лаунчер, пока играете:** в нём работает мост.

## Что проверяет и чинит лаунчер

| Строка | Что значит |
|---|---|
| Python 3 | найден ли настоящий Python ≥ 3.8 (заглушка из Microsoft Store не считается) |
| Пакет мода | где лежит и какой версии; есть ли на GitHub более новая (у всех игроков версия должна совпадать) |
| Warband | папка игры (Steam, GOG, стандартные пути) и установлен ли модуль `Warband Coop Campaign` |
| Radmin VPN | включён ли, ваш адрес 26.x.x.x (кнопка «Копировать мой IP») |
| Связь с хостом | пинг и TCP-порт 7350 моста хоста: сразу понятно, «хост не в сети» это или «хост не нажал Играть» |
| Брандмауэр (хост) | есть ли правило для порта 7350. **Папки… → Разрешить мост в брандмауэре** создаёт правило и снимает старую блокировку python.exe, которая остаётся, если когда-то в окне Windows нажали «Отмена» |
| Настройки Warband | `start_windowed = 1` и у друга `look_for_server_on_this_machine = 1` в `rgl_config.txt`. Лаунчер включает их сам, если игра закрыта; копия файла сохраняется в `.bak` |
| Мост | нет ли уже запущенной копии от `host.bat`/`join.bat`: два моста на одном ПК мешают друг другу |

Во время игры лаунчер читает вывод моста и пишет понятным языком: «связь с хостом есть»,
«сохранение получено — загрузите слот sg00», «неверный пароль», «разные версии мода»,
«друг подключился», «порт занят».

## Где что лежит

- Настройки лаунчера: `%APPDATA%\WarbandCoopLauncher\launcher.json`. Пароль зашифрован средствами
  Windows (DPAPI), прочитать его можно только под вашей учётной записью.
- Пакет мода: `%LOCALAPPDATA%\WarbandCoopLauncher\package\<версия>`.
- Журналы моста: `Документы\Warband Coop Campaign\` (`bridge.log` у хоста, `join.log` у друга).
  Сообщения об ошибках мода отправляйте [его автору](https://github.com/zABUz-rgb/Warband-Coop-Campaign#как-сообщить-об-ошибке).
- Сохранения кооператива: `Документы\Mount&Blade Warband Savegames\Warband Coop Campaign`.
  Держите там только сохранения текущей совместной кампании: мост отдаёт друзьям самое свежее из них.

## Если что-то не так

- Окно не открывается: запустите `CoopLauncher_Check.bat`. Он выведет ту же проверку в консоль.
  Ошибки лаунчера пишутся в `%APPDATA%\WarbandCoopLauncher\launcher.log`.
- Друг видит «хост в сети, но мост не отвечает». Хост ещё не нажал «Играть» или брандмауэр блокирует
  порт. Хосту: **Папки… → Разрешить мост в брандмауэре**.
- «Хост не отвечает» совсем. Проверьте, что оба в одной сети Radmin и у хоста зелёный значок.
- Скрипт заблокирован политикой выполнения. `CoopLauncher.bat` запускает его с `-ExecutionPolicy Bypass`,
  поэтому открывайте лаунчер через `.bat`, а не через `.ps1`.

## Ограничения

- Работает только под Windows 10/11 (Windows PowerShell 5.1 и WinForms).
- В игре (два ПК, Warband, Radmin) лаунчер ещё не прогонялся. Вызов моста и разбор его сообщений
  проверены на настоящем `coop_bridge.py` из релиза 1.2: хост и друг на одной машине, передача
  сохранения, отказ при неверном пароле.
- Стабильность самого кооператива определяет мод Warband Coop Campaign. Сейчас он в открытой бете.
