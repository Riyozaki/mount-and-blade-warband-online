# Формат сохранения мира и профилей игроков (`Save Format`)

В `Calradia Online` состояние хранится в двух синхронизированных слоях, что позволяет миру работать годами, переживать перезапуски сервера и исключать повреждение сейвов при внезапном отключении питания:

1. **Нативный сейв движка WSE2 (`sg00.sav`)** — хранит геометрию глобальной карты, позиции ИИ-партий и базовые слоты мира.
2. **Авторитарное JSON-хранилище Lua (`Modules/CalradiaOnline/lua/saves/<world_name>/`)** — хранит профили всех зарегистрированных игроков по `player_uid`, инстансы квестов, предприятия в городах, дипломатию королевств игроков и журнал транзакций.

---

## 1. Структура каталога сохранения мира

```
saves/
└── default_world/
    ├── world_meta.json          # Календарная дата, версия схемы, счётчик эпох, дипломатия
    ├── quests.json              # Активные и на кулдауне инстансы квестов
    ├── enterprises.json         # Предприятия (цеха) каждого игрока в 22 городах
    ├── kingdoms.json            # Королевства игроков, вассалы, феоды, законы, пиры
    ├── companions.json          # Статус, локация и экипировка 16 уникальных спутников
    ├── players/
    │   ├── <player_uid_1>.json  # Полный профиль игрока №1 (атрибуты, навыки, инвентарь, армия)
    │   └── <player_uid_2>.json  # Полный профиль игрока №2
    └── backups/
        ├── snapshot_001/        # Кольцевой буфер последних 5 атомарных бэкапов
        └── ...
```

---

## 2. Правило атомарной записи

Ни один файл сохранения никогда не перезаписывается напрямую поверх существующего:
1. Сериализованный с отсортированными ключами JSON записывается в `<filename>.tmp` + контрольная сумма `CRC32/SHA256`.
2. Предыдущая валидная копия ротируется в `backups/`.
3. Выполняется атомарный `os.rename("<filename>.tmp", "<filename>")`.
4. При старте сервера, если основной файл оборван (например, при аварийном выключении ПК хоста), `persistence.lua` автоматически восстанавливает последний консистентный снимок из `backups/`.
