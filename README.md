# mount-and-blade-warband-online

Кооператив Mount & Blade: Warband на общей карте через Radmin VPN.

- **[`launcher/`](launcher/README.md)** — лаунчер «в одну кнопку» для мода
  [Warband Coop Campaign](https://github.com/zABUz-rgb/Warband-Coop-Campaign): установка и обновление
  мода, проверка Radmin и связи с хостом, запуск моста и игры. Запуск — `launcher/CoopLauncher.bat`.
- [`docs/REVIEW_calradia_online.md`](docs/REVIEW_calradia_online.md) — ревью ветки
  `arena/9dc45ff9-…` (Calradia Online) и почему основой выбран другой мод.
