# Calradia Online — Mount & Blade: Warband Cooperative Sandbox Campaign

Полноценная кооперативная онлайн-кампания со свободной песочницей (**Co-op + PvP**, 2–16 игроков онлайн, до 32 постоянных героев в мире) для *Mount & Blade: Warband* (1.174 + WSE2).

Полная архитектурная и игровая спецификация зафиксирована в **[`PROJECT_PLAN.md`](./PROJECT_PLAN.md)**.

---

## Что реализовано в проекте

1. **Полная кооперативная кампания (`lua/` — движок на LuaJIT 2.1 для WSE2)**:
   - **`lua/auth.lua` + `lua/sha256.lua`**: криптографическая идентификация `identity.key` (HMAC-SHA256 challenge-response) без привязки к Steam (одинаково работает на Steam, GOG и Standalone версиях без обхода DRM), защита никнеймов, переподключение в свою партию и таймер защиты от combat-log.
   - **`lua/persistence.lua` + `lua/flight_recorder.lua` + `lua/json.lua`**: атомарные сохранения мира (`.tmp` -> `rename` + конверт SHA-256 + 5 ротационных бэкапов `.bak1..5` с автоматическим самовосстановлением при повреждении файла) и кольцевой `cofr` Flight Recorder.
   - **`lua/economy.lua`**: создание персонажа по биографии, прокачка атрибутов/навыков/владения оружием, сервер-авторитетный инвентарь с защитой `snapshot_epoch`, живая торговля в городах с навыком `Trade`, 9 типов предприятий (мастерских) индивидуально для каждого игрока, апгрейд войск, полуночный `Trainer`, 14-часовой цикл еды/морали, недельный бюджет и двухфазный защищённый P2P-обмен между игроками.
   - **`lua/quests.lua`**: инстансированные серверные квесты (гильдмейстеры, старосты, лорды, маршалы, леди) с кулдаунами и совместным выполнением в Братстве + глобальный пул всех **16 уникальных компаньонов Кальрадии** (`Borcha`..`Klethi` — строго без клонирования, с моралью симпатий/антипатий и миссиями на `Right to Rule`) + наёмные офицеры-специалисты.
   - **`lua/battles.lua`**: активные узлы битв на глобальной карте, **динамический вход друзей подкреплением прямо в идущий 3D-бой (`LIVE_REINFORCEMENT`)**, индивидуальный расчёт `Surgery` (`25% + 4% * skill`), `First Aid`, `Looting`, распределение пленных (`Prisoner Management`), судьба побеждённых лордов (`+Honor` или плен), кооп-плен (выкуп, спасение на карте, совместный штурм тюрьмы) и **общие многопользовательские турниры на 6 раундов со ставками**.
   - **`lua/politics.lua`**: консенсус скорости времени карты (`Pause / 1x / 3x / 5x`) с экстренным торможением при перехвате, Братства (альянсы игроков), осады (`Engineer` для лестниц/башен, голод гарнизона), наёмничество, вассалитет у ИИ-королей **или у друга-игрока**, собственные суверенные королевства игроков (`fac_coop_kingdom_0..15`), выборы маршала, постройки в наделах, претенденты, ухаживания/свадьбы (включая династические браки между игроками) и пиры.
   - **`lua/ipc_bridge.lua` + `lua/main.lua`**: атомарный мост связи Кампания <-> `CoopHostSupervisor` <-> Пул тактических 3D-серверов и точка входа WSE2 (`@coop_*` RPC).

2. **Модульная система Warband 1.174 + WSE2 (`module_system/`)**:
   - Полностью портирована на **Python 3** (`python3 module_system/build_module.py`), исправлен баг апстрима `Native-Coop` в `wse_window_opened`, экспортируются все 32 `.txt` файла и 52 заголовка `lua/msfiles/`.
   - Расширения `module_system/coop/` добавляют 32 профиля героев (`trp_coop_hero_0..31`), офицеров, 16 фракций отрядов и 16 королевств игроков (`fac_coop_kingdom_0..15`), битово-симметричные композитные каналы WSE2 (`110..115`), раздельные тактические дивизии командиров (`agent_set_division` + `team_set_order_listener`), HUD консенсуса скорости карты и окно P2P-обмена.

3. **Нативный C++17 рантайм, Single-Port UDP Mux и Установщик / Обновлятор / Деинсталлятор (`native/`)**:
   - `coop_host_supervisor`: мультиплексор `CoopUdpMux` (весь трафик Кампании и до 8 параллельных 3D-битв идёт через **один публичный UDP-порт**) + оркестратор пула боевых серверов.
   - `coop_net_proxy`: клиентский помощник идентичности и проверки транспорта. Сейчас реализован только Direct IP через однопортовый UDP-мультиплексор (LAN и VPN работают как обычные IP-адреса). Relay и Steam P2P пока **не реализованы**; Steam runtime лишь определяется, но не используется. `coop_host_supervisor --relay-self-test` проверяет реальную пересылку через мультиплексор.
   - `calradia_launcher`: управление профилем `identity.key`, закладками серверов и настройками хоста.
   - `calradia_installer`: автопоиск папки *Mount & Blade: Warband* (Steam VDF / GOG / Standalone), локальное копирование базовых ресурсов из `Modules/Native`, **чистое обновление (`update`)** с полным удалением всех устаревших файлов мода и сохранением `saves/` + `identity.key`, и **полное чистое удаление (`uninstall`)**.

## Быстрая сборка и проверка (Offline Build & Verification)

```bash
# 1. Скомпилировать всю Модульную систему (.txt + lua/msfiles) и C++17 утилиты
make build

# 2. Запустить полный набор статических линтеров, LuaJIT-тестов, фаззинга синхронизации и E2E тестов установщика
make test

# 3. Собрать готовый пакет для установщика в dist/CalradiaOnlinePackage
make package
```

## Установка, Чистое Обновление и Полное Удаление

```bash
# Автопоиск установленной игры и установка в пару кликов:
./build/native/calradia_installer install --package dist/CalradiaOnlinePackage --version 1.0.0

# Чистое обновление до новой версии (удаляет 100% старых файлов мода, сохраняя сейвы и ключ игрока):
./build/native/calradia_installer update --package dist/CalradiaOnlinePackage --version 1.1.0

# Полное удаление мода без следов в папке игры:
./build/native/calradia_installer uninstall
```

## Запуск (Windows, в один щелчок)

Готовый архив `CalradiaOnline-Windows-x64` содержит батники рядом с `calradia_installer.exe`:

1. **Установка / обновление / удаление** — `Install_CalradiaOnline.bat`, `Update_CalradiaOnline.bat`, `Uninstall_CalradiaOnline.bat`. Установщик сам находит папку Warband (Steam, GOG, Standalone) и предупреждает перед удалением сохранений.
2. **Хост кампании** — `Host_Campaign_Server.bat`: запускает campaign-сервер WSE2, 2 боевых сервера и шлюз `coop_host_supervisor`. Друзьям нужно открыть **только UDP 7240** (или подключиться через VPN).
3. **Игрок** — `Play_CalradiaOnline.bat`: спрашивает ник, готовит `identity.key` и запускает Warband с модулем `CalradiaOnline`.

Требования: установленный Warband 1.174 и **WSE2** (для серверных `mb_warband_wse2_dedicated*.exe`) в папке игры.

Порты: игрокам виден один публичный порт `7240`; внутренние порты игровых серверов (`7241` кампания, `7242`, `7244`, … боевые слоты) слушают только на локальной машине хоста.

> Статус: батники собраны по схеме запуска родственных WSE2-проектов, но сквозной запуск с двумя ПК ещё **не проверен в игре** — это следующий шаг тестирования.
